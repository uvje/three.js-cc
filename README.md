# Деревня Нацумэ · なつめ村

Летняя японская деревня на three.js: от первого лица, пешком и на велосипеде-мамачари, со сменой суток и полностью процедурным звуком.

## Запуск

Нужен любой статический HTTP-сервер (модули ES не работают через `file://`):

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000. Сборка не нужна — three.js лежит в `lib/`.

## Управление

| Клавиши | Действие |
|---|---|
| W A S D | идти / на велосипеде: W — педали, S — тормоз, A/D — руль |
| Мышь | смотреть по сторонам (клик — захват курсора) |
| Shift | бежать / налечь на педали |
| E | сесть на велосипед или слезть, купить, присесть, помолиться |
| R или ЛКМ | звонок велосипеда |
| L | фара |
| B | позвать велосипед, если он далеко |
| T (держать) | ускорить время; `[` `]` — скорость суток |
| M / Tab | карта / летний дневник со штампами |
| H | скрыть интерфейс · Esc — пауза и настройки |
